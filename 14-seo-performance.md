# SATVEX — SEO and Performance

## SEO
Implement:
- semantic HTML
- page titles
- meta descriptions
- canonical URLs where appropriate
- Open Graph metadata
- product-friendly URLs/slugs
- robots.txt
- sitemap.xml

## Product SEO
Product pages should have:
- unique title
- unique meta description
- descriptive slug
- image alt text
- structured product information where appropriate

## Performance
Optimize:
- image size
- image format
- lazy loading
- code splitting
- API calls
- caching
- CloudFront delivery

## Images
Do not load all full-resolution images on initial page load.

Use:
- thumbnails
- responsive sizes
- lazy loading

## API
Avoid unnecessary requests.
Cache public product/catalog data where appropriate.

## Frontend
Avoid:
- huge JS bundles
- unnecessary dependencies
- repeated API calls
- blocking media

## UX Performance
Use:
- skeletons
- progressive image loading
- optimistic interactions where safe
- clear loading states

## Mobile
Prioritize mobile performance because the product experience is expected to be mobile-heavy.
